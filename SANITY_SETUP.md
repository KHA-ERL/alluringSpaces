# Sanity Setup

Create one `Environment` document in Sanity Studio at `/studio`.

Use it for values that will change as the firm grows:

- Completed spaces
- Design awards
- Trusted artisans
- Cities served
- WhatsApp number

The WhatsApp number should use international format without `+`, spaces, or dashes.
Example: `2348012345678`.

Create one `Socials` document in Sanity Studio at `/studio`.

Use it for footer social media links:

- TikTok URL
- Instagram URL
- Facebook URL

The homepage stats and contact form read these values automatically. The site
falls back to local defaults until the Sanity project ID, dataset, and
Environment/Socials documents are configured.
